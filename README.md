# Cuadrilla landing page

The marketing site for [Cuadrilla](https://github.com/Remy349/cuadrilla). It is a single static page built with Astro and Tailwind CSS v4. The only JavaScript is a few small vanilla scripts for copy-to-clipboard, the install tabs, the mobile nav and scroll reveal. The FAQ uses native `<details>`.

## Run

```bash
pnpm install
pnpm dev            # http://localhost:4321
```

## Build

```bash
pnpm build          # astro check && astro build → dist/
pnpm preview        # serve dist/ locally
```

## Edit content

All copy lives in `src/data/*.ts` as typed objects. Components only render it.

| File | What's in it |
|---|---|
| `site.ts` | **Version** (`VERSION`), repo URL, links, nav, SEO title/description, UI labels |
| `hero.ts` | Headline, subhead, terminal mockup script |
| `problems.ts`, `flow.ts`, `tiers.ts`, `agents.ts`, `briefs.ts`, `safety.ts`, `commands.ts` | Section content |
| `install.ts` | Install commands (built from `VERSION` and the repo URL), notes, models snippet |
| `faq.ts`, `cta.ts` | FAQ, final CTA, footer |

To release a new version, change `VERSION` in `src/data/site.ts`. The pin-version commands, the hero badge, the footer, the JSON-LD and the OG image all read it from there. Run `pnpm og` to regenerate the OG image.

Wrap text in `` `backticks` `` inside data strings to render it as inline code. This works in the safety items, FAQ answers and install notes.

Design tokens (colors, fonts, radius) are defined in `src/styles/global.css` under `@theme`.

## Deploy

The output is plain static files in `dist/`, so any static host works (GitHub Pages, Netlify, Cloudflare Pages, Vercel, S3). Before deploying, set `site` in `astro.config.mjs` to the production URL. It drives the canonical URL, the Open Graph URLs and the sitemap.

## OG image

`public/og.png` (1200×630, ~20 KB) is generated by `scripts/generate-og.mjs` with sharp. It uses Oswald from `@fontsource/oswald`, a dev dependency used only for this script.
